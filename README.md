# Codification-Mission

High-level description of the codification mission. Invites scrutiny and iteration. 

1. What:

    0. Publish legal documents like software source code:

    1. As modules
    2. Versioned
    3. On GitHub
    4. Rendering into full documents while retaining the modular structure.  The principle contribution of CommonAccord is a simple paradigm for handling complex documents while retaining the power of the participants (parties, lawyers, etc.) to override any part that they think needs tweaking.

2. Why:  

    0. Codification will make:

    1. Law better
    2. Economics better
    3. Politics better

3. How:

    1. Share legal text, including inviting existing model document projects and ontologies.

    2. Reimplement the software

        1. Simple improvement
        2. Assimilate some "graph" notions
        3. Interface to existing ecosystems - ontologies, CLM, CRM, Excel, blockchains, etc.

    3. Create governance structures

        1. A Center for Decentralized Law
        2. Sector-specific efforts - jurisdictions, trade groups, legal domains, etc.
